# Velora Motors — Car Showroom Frontend

A professional, responsive car showroom frontend built with HTML5, CSS3, vanilla JavaScript and Bootstrap 5.

## Included pages

- Home
- Cars / vehicle inventory
- Brands
- Offers
- About
- Services
- Gallery
- Contact
- Login
- Admin dashboard

## Dynamic frontend features

- Vehicle inventory rendering from JavaScript data
- Brand and category data
- Search
- Brand/category/fuel filters
- Price/budget filtering from homepage
- Sorting
- Vehicle comparison selection (up to 3)
- Test-drive booking modal
- Contact form feedback
- Demo admin authentication
- Admin vehicle table
- Add vehicle UI
- Test-drive booking overview
- Inventory category chart bars
- Responsive Bootstrap navigation


This is frontend-only authentication. It is not secure and must be replaced with server-side authentication before production.

## Run

Open `index.html` in a browser, or serve the folder using a local server.

For example with VS Code Live Server:
1. Open this folder.
2. Right-click `index.html`.
3. Choose "Open with Live Server".

## Backend integration points

Replace the arrays in `js/data.js` and frontend handlers with API calls for:
- Vehicles CRUD
- Brands/categories CRUD
- Authentication
- Test-drive bookings
- Contact/enquiry storage
- Offers
- User accounts

The Unsplash image URLs are demo assets and can be replaced with your own hosted images.
